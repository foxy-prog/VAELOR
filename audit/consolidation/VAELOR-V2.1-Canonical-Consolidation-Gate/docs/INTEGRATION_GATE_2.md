# VÆLOR V2.1 — Integration Gate 2

## Gate name
Canonical Contract + Persistent Runtime State

## Exit criteria

1. One canonical authority, trust-zone, risk, and work hierarchy.
2. Mission Kernel remains the authoritative mission lifecycle owner.
3. Planning, Opportunity, and Initiative modules do not own execution state.
4. Tool Gateway remains the mandatory external execution boundary.
5. Runtime state survives process restart.
6. Snapshot schema is versioned and written atomically.
7. Durability journal records commits.
8. Restart continuity test passes.
9. TypeScript compilation passes.
10. No external AI provider is required for runtime operation.

## Result

This gate establishes **controlled persistent runtime**, not full autonomous production operation. The next gate is production data infrastructure and complete end-to-end cognitive-cycle integration.
