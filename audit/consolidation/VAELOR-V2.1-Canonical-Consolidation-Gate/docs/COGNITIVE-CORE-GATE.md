# VÆLOR V2.1 — Cognitive Core Gate

## Purpose
Establish an internal, deterministic cognition boundary without making an external foundation model a runtime dependency.

## Principle
VÆLOR owns the cognitive loop. Inference is a replaceable mechanism used to generate interpretations/proposals; governance, memory, world state, authority, mission state, verification, recovery, and evidence remain owned by VÆLOR.

## Native baseline
The included `NativeInferenceEngine` is intentionally conservative. It performs structured interpretation, proposal formation, and anticipation from authorized structured observations. It does not claim human-level general intelligence.

## Acceptance
- Structured observations produce deterministic interpretations.
- Proposals include rationale and confidence.
- Untrusted observations are not granted authority.
- No authority is escalated by inference.
- The cognitive runtime can pause for authorization.
- Verification remains outside inference.
